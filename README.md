# Намёк понял (Just One) — Web Game

Онлайн-версия настольной игры «Just One» с поддержкой Discord-бота для изолированного голосового режима.

## Быстрый старт

```bash
npm install
npm start
```

Игра будет доступна по адресу `http://localhost:3000/just-one`.

### Режим отладки (1 игрок)

```bash
npm run debug
```

## Настройка

### Через `config.json`

Скопируйте `config.example.json` → `config.json` и заполните нужные поля:

```json
{
  "port": 3000,
  "discord": {
    "token": "YOUR_DISCORD_BOT_TOKEN"
  }
}
```

| Поле | Описание |
|------|----------|
| `port` | Порт сервера (по умолчанию 3000) |
| `discord.token` | Токен Discord-бота (необязательно) |

### Через переменные окружения

Для деплоя на Railway / Render / Docker можно использовать переменные окружения вместо `config.json`:

| Переменная | Описание |
|-----------|----------|
| `PORT` | Порт сервера |
| `DISCORD_TOKEN` | Токен Discord-бота |

## Discord-бот (опционально)

Discord-бот позволяет автоматически заглушать угадывающего игрока в голосовом канале Discord на время раунда.

> **Примечание:** `discord.js` — опциональная зависимость. Игра полностью работает без неё.

### Создание бота

1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications)
2. Создайте новое приложение → Bot → скопируйте токен
3. Включите **Privileged Gateway Intents**: `MESSAGE CONTENT`, `SERVER MEMBERS`, `PRESENCE`
4. Пригласите бота на нужные серверы по ссылке: `https://discord.com/oauth2/authorize?client_id=YOUR_CLIENT_ID&scope=bot&permissions=8391680`

### Команды бота

| Команда | Описание |
|---------|----------|
| `!link` | Генерирует 6-символьный код привязки (действителен 5 минут) |
| `!unlink` | Отвязывает Discord-аккаунт от игрового |
| `!status` | Показывает текущие привязки |

### Привязка Discord-сервера

```
1. В игре: хост нажимает кнопку 🖥 (DNS) в настройках
2. Вводит ID своего Discord-сервера (ПКМ на сервер → «Копировать ID», нужен режим разработчика)
3. Если бот не добавлен на сервер или нет прав — появится ссылка для добавления бота
```

### Привязка игрока

```
1. В Discord: !link → бот отправляет код в ЛС
2. В игре: настройки (⚙) → кнопка 🔗 → ввести код
3. После привязки бот автоматически заглушает/разглушает игрока
```

### Как работает изолированный режим

- Хост включает режим кнопкой 🎧 в настройках
- Когда игрок становится угадывающим (фазы 1–3), бот его заглушает в Discord
- Сразу после угадывания слова (переход на фазу 4) заглушение снимается
- Бот проверяет состояние каждую секунду

## Деплой на Railway

1. Создайте новый проект на [Railway](https://railway.app)
2. Подключите GitHub-репозиторий
3. Добавьте переменные окружения:
   - `DISCORD_TOKEN` — токен бота
4. Railway автоматически установит зависимости и запустит `npm start`
5. `PORT` устанавливается Railway автоматически

> Railway использует `npm start`, который запускает `node server.js`. Файл `config.json` не нужен — все настройки через переменные окружения.

## Архитектура

```
server.js          — Express + Socket.IO сервер, точка входа
module.js          — Игровая логика (состояние комнат, фазы, голосование)
discord-bot.js     — Discord-бот (опциональный модуль)
public/
  app.html         — Главная страница
  app.jsx          — React-приложение
  hostControls.jsx — Панель управления хоста
  standalone.js    — Стабы платформенных глобалов
  style.css        — Стили
  translation_ru.js — Локализация
```

### Модульность

- **Без Discord:** игра работает полностью автономно, `discord.js` не загружается
- **С Discord:** бот запускается только при наличии `DISCORD_TOKEN` / `config.discord.token`
- **`module.js`** не зависит от Discord напрямую — он выставляет `room.userDeaf`, а бот читает это состояние
- **`discord-bot.js`** — отдельный класс, подключаемый через `require()` в `try/catch`
